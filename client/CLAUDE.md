# client/ (`@devdigest/web`) — CLAUDE.md

Next.js studio UI; talks to the API on :3001. Project map: [../CLAUDE.md](../CLAUDE.md)

## Stack
Next.js 15.5 (App Router) · React 19 · TanStack Query 5 · next-intl 3 · Tailwind 4 · Zod 3.25 ·
Vitest 2 + jsdom + Testing Library 16

## Commands (pnpm)
- `pnpm dev` — web on :3000 (needs the API running)
- `pnpm typecheck` — run before declaring work done
- `pnpm test` — vitest + jsdom (no Docker)
- `pnpm build`

## Map
- `src/app/` — routes (onboarding, settings, agents, repos/[repoId]/pulls/[number])
- `src/lib/` — API client (`api.ts`), hooks, providers, repo context
- `src/components/` — app-specific components
- `src/vendor/ui/` — shared UI kit (primitives, shell, charts, icons)
- `src/vendor/shared/` — client copy of the Zod contracts
- `messages/` — next-intl translation files; `src/test/` — test setup

## Conventions
- All user-visible strings go through next-intl (`messages/en`), never hard-coded.
- Reuse `src/vendor/ui` components before writing new ones.
- Server calls go through `src/lib/api.ts`; types come from `vendor/shared`, not local re-declarations.

## Gotchas
- `src/vendor/shared` is **not** linked to the server copy and has already drifted.
  Diff it against `../server/src/vendor/shared` before relying on or changing a contract.

## Do not touch
- `next-env.d.ts` — generated by Next.js.
